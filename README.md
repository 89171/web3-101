# Web3 101

> 最容易读懂的 Web3 入门手册。

[English version](README.en.md)

不堆术语、不喊口号、不教你炒币。一句话讲清「它到底是什么」，一个对照对齐已有认知。

> 内容面向入门理解，不构成投资、法律、税务或安全承诺。Web3 工具、费用、规则变化很快，实操前请以官方文档和钱包提示为准。


## 这本手册不做什么

- 不推荐项目，不喊单，不提任何币价
- 不替你判断投资、合规或税务风险
- 不写「Web3 将颠覆世界」之类的话
- 不假设你会写代码

## 阅读路径

如果你只有 30 分钟，读 **第 1 章** 就够了。  
如果你想能跟人聊上几句，读完 **第 1～3 章**。  
如果你想看懂大多数 Web3 资讯，读完 **第 1～5 章**。
