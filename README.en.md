# Web3 101

> A beginner-friendly Web3 handbook.

[Chinese version](README.md)

No jargon overload, no hype, no trading calls. This handbook explains what Web3 is in plain language, using comparisons to concepts you already know.

> This content is for beginner education only. It is not investment, legal, tax, or security advice. Web3 tools, fees, and rules change quickly, so always verify with official documentation and your wallet prompts before taking action.

## What This Handbook Does Not Do

- It does not recommend projects, tokens, or prices.
- It does not judge investment, compliance, or tax risk for you.
- It does not claim that Web3 will change everything.
- It does not assume you can code.

## Reading Path

If you only have 30 minutes, read **Part 1**.  
If you want to hold a basic conversation, read **Parts 1-3**.  
If you want to understand most Web3 news, read **Parts 1-5**.
