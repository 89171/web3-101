# 13. DAO

## 一句话理解

DAO = **去中心化自治组织**。一群人**用钱包投票管理一个共同的金库或项目**。理想状态下没有单一 CEO 说了算，关键规则尽量写在链上。

## 它和「公司」有什么不一样

传统公司是这样运作的：

- 创始人/CEO 拍板大方向
- 董事会重大决策
- 员工执行
- 股东大会一年开一次，举手投票

公司是**自上而下**的。管理层有信息和权力的优势。

DAO 想换一种活法：

- 没有单一 CEO 说了算，没有传统公司那种固定员工层级（至少理论上）
- 持有这个 DAO 的「治理代币」就有投票权
- 重要决策通过链上提案和投票决定
- 金库的钱怎么花，由集体投票决定
- 规则和执行都用智能合约保证

一个粗略的对照：

| | 公司 | DAO |
|---|---|---|
| 权力来自 | 股权 + 管理职位 | 治理代币持有量 |
| 决策方式 | CEO 决定 + 董事会批准 | 提案 + 全员投票 |
| 钱怎么管 | 财务+老板批 | 链上金库 + 智能合约 |
| 入会方式 | 入职面试 / 投资入股 | 买治理代币就行 |
| 透明度 | 内部信息不公开 | 链上资金和投票公开，但线下沟通、法律实体、团队决策未必公开 |
| 跨国 | 难（注册地、税务、法律） | 没有国界，链上就行 |

## DAO 在实际中长什么样

「DAO」这个词被滥用得很厉害，听上去高大上其实经常没那么神。看几个真实的例子有助于建立直觉：

### 1. 协议治理型 DAO

最常见的一类。某个 DeFi 协议（比如 Uniswap、Aave）发行治理代币（UNI、AAVE），持有者可以投票决定：

- 协议参数怎么调（手续费比例、清算阈值等）
- 协议金库的钱怎么花
- 要不要上线新功能、新链

代表：**Uniswap DAO**、**Aave DAO**、**MakerDAO**、**Compound DAO**

这是「DAO」概念最务实的形态。

### 2. 投资型 DAO

一群人凑钱、投票决定投什么。

代表：**The LAO**、**MetaCartel Ventures** 等

跟传统风投基金的区别：成员通过买入「份额代币」加入，投票决定投哪个项目，收益按份额分。

### 3. 收藏型 DAO

一群人凑钱**买一个东西**。

最著名的：**ConstitutionDAO**——2021 年一群人凑了约 4700 万美元想拍下美国宪法第一版印刷品，最后没拍到，钱按比例退回。整个过程**几天内组织起来 17000 人**，纯靠链上协调。

这是 DAO 最有 Web3 浪漫主义味道的形态。

### 4. 社区 / 文化 DAO

围绕一个文化、IP、兴趣组建的社区，持有某个 NFT 或 token 就能进。

代表：早期的 **Friends With Benefits (FWB)** 等

很多这类 DAO 现在已经凉了——「治理」是真的难，「文化」是真的难维系。

### 5. 服务型 DAO

一群专业人士组成的 DAO，对外接活。客户付钱给 DAO 金库，DAO 内部分工分钱。

代表：**Raid Guild**（开发者）、**LexDAO**（法律服务）

## DAO 是怎么投票的

主流方式有几种：

### 1. On-chain Voting（链上投票）

提案和投票都在链上，每张票要花 Gas。

优点：完全可验证，结果直接由智能合约执行。  
缺点：投票要花钱，参与率低。

### 2. Off-chain Voting（链下投票）

最流行的是 **Snapshot**。投票用钱包**签个消息**（不花 Gas、不上链），系统按签名时的代币持有量统计票数。

执行结果时，DAO 多签钱包根据投票结果**手动操作**。

优点：免费、参与门槛低。  
缺点：执行依赖人，**不是 100% 自动**。

### 3. 委托投票（Delegation）

你把自己的投票权委托给一个「代表」，让他替你投。

优点：解决「我没时间研究每个提案」的问题。  
缺点：权力集中到少数大代表手里，**「去中心化」的成色打折**。

## DAO 的现实问题（去掉理想滤镜）

DAO 听起来很美好，但实操中坑也不少：

### 1. 投票率极低

绝大多数 DAO 的提案，**真实参与投票的人不到代币持有者的 10%**。大部分人买了 token 但从来不投票。结果就是**少数活跃用户和大户决定一切**。

### 2. 大户支配

治理代币按持有量计票，意味着**有钱人有更多票**。这跟传统公司的「同股同权」其实没本质区别——只是入场资格变了。

### 3. 治理攻击

有人可以借大量代币、闪电贷数百万 token，在某个时刻投票通过一个对他有利的提案（比如把金库的钱划给自己），然后还掉借的币。

历史上这种事真发生过。

### 4. 决策效率低

每个提案要走「讨论 → 提案 → 投票 → 执行」的流程，常常一个月起步。对于需要快速反应的场景（比如市场剧烈波动时调整协议参数），DAO 慢得让人崩溃。

很多协议的解决方案是「**治理决定方向，运营团队负责执行**」——但这又有点回到了传统公司的样子。

### 5. 法律地位模糊

DAO 在大多数国家**没有法律实体**。这意味着：

- 出了事告谁？告 DAO 没法告。
- 跟外部签合同？谁代表 DAO？
- 收益怎么报税？

近年怀俄明、马绍尔群岛等地有「DAO LLC」框架试图解决这些问题，但还远不通用。

### 6. 「DAO 化」滥用

很多项目挂着「DAO」的名号，但**实际控制权完全在创始团队手里**——投票门槛高、代币集中、提案能被否决。「Decentralization Theater」（去中心化表演）这个词就是为它们造的。

## 怎么辨别一个 DAO 是不是真 DAO

如果你想参与一个 DAO，先问自己：

1. **代币持有分布**：创始团队占多大比例？前 10 名占多大？太集中 = 不是真 DAO
2. **历史提案**：有没有真正实质性的提案？提案通过率多少？参与投票的钱包数？
3. **金库怎么管**：是合约自动执行还是多签人工操作？多签人是谁？几个人能动？
4. **关键决定能不能被否决**：创始团队是不是有「红色按钮」可以推翻投票结果？

如果上面这些一查就有问题，那它只是「营销叫 DAO」的传统团队。

## 怎么记这一章

| 关键点 | 一句话 |
|---|---|
| DAO 本质 | 用钱包投票管理共同金库的组织 |
| 投票权 | 来自治理代币持有量 |
| 治理工具 | 链上投票贵但权威，Snapshot 链下投票免费 |
