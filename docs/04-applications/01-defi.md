# 11. DeFi 是什么

## 一句话理解

DeFi = **去中心化金融**。把银行、券商、保险公司做的部分事情，用智能合约重新做一遍——核心规则在链上执行，但现实里仍然可能有团队、前端、治理和监管边界。

## 它和银行的根本区别

传统金融里，所有金融服务都需要一个**中心化机构**：

- 你想存钱赚利息 → 银行
- 你想借钱 → 银行
- 你想换外币 → 银行 / 货币兑换商
- 你想买股票 → 券商
- 你想买保险 → 保险公司

这些机构干的事，本质上都是「按一套规则记账 + 风险管理」。

DeFi 的想法是：

> **既然是「按一套规则记账」，那把规则写成代码，部署到区块链上，谁都不用了，让代码自己跑。**

这就是「**智能合约**」干的事。它是一段部署在链上的程序，任何人都能调用，调用结果按预定规则执行。理想状态下，协议层不会因为你是谁而拒绝你；但现实里，项目前端、预言机、治理多签、监管要求都可能影响你的使用体验。

| | 传统金融 | DeFi |
|---|---|---|
| 谁执行规则 | 银行/券商员工 + IT 系统 | 链上的智能合约 |
| 谁审核你 | KYC、风控、客户经理 | 协议层通常不审核身份；前端和入口可能会限制 |
| 营业时间 | 9:00-17:00，节假日休 | 7×24，永不打烊 |
| 跨境 | 复杂、慢、贵 | 没有「跨境」概念 |
| 出问题怎么办 | 投诉、监管、打官司 | **基本上没人管你**——这是 DeFi 最现实的代价 |

## 一个具体例子：DeFi 借贷 vs 银行借贷

最容易理解的 DeFi 应用是借贷。我们对比一下：

### 在银行借 10 万人民币

1. 准备一堆资料：身份证、工资流水、社保、征信报告
2. 提交申请，等审批 1~7 天
3. 客户经理审核你的还款能力，决定批不批、利率多少
4. 批了之后，签合同，钱到账
5. 按月还款，逾期上征信

整个过程的核心是：**银行需要知道你是谁，能不能还得起**。

### 在 Aave（DeFi 借贷协议）借 1 万 USDC

1. 打开 Aave 网站，连接钱包
2. 先**抵押**一些资产，比如 ETH 价值 1.5 万美元
3. 点几下，借出 1 万 USDC，几秒钟到账
4. 想还的时候还，没有「逾期」概念
5. 如果你抵押的 ETH 跌了，跌到一个阈值，系统**自动清算**你的抵押品

整个过程的核心是：**协议根本不在乎你是谁，只在乎你的抵押品够不够**。

这就是为什么 DeFi 借贷通常叫「**超额抵押**」——你可能需要先放 120%～200% 甚至更高价值的抵押品，才能借出 100%。具体比例取决于资产波动、协议参数和市场风险。它没有传统信用审核（链上不知道你是谁），所以只能靠资产价值来兜底。

> 这听上去很反直觉：「我都有 1.5 万了，为啥还要借 1 万？」  
> 因为很多人不想卖掉 ETH（觉得会涨），但又需要稳定币花。抵押 ETH 借 USDC，既保留 ETH，又能用上现金。

## DeFi 里的几大类应用

按功能粗分，主流 DeFi 应用大致这几类：

### 1. DEX（去中心化交易所）

链上的「股票交易所 + 货币兑换商」——你想把一种代币换成另一种，DEX 自动给你算价格、自动撮合。

代表：**Uniswap**（以太坊）、**Curve**（稳定币之间互换）、**Jupiter**（Solana）

下一章 [12. DEX 与 AMM](02-dex.md) 会单独讲它的运作机制。

### 2. 借贷协议（Lending）

存币赚利息 / 抵押借币。上面 Aave 那个例子就是这种。

代表：**Aave**、**Compound**、**Spark**

注意：**「存币赚利息」的钱从哪来？** 来自那些借币的人付的利息。所以利率不是平台拍脑袋定的，是「借出需求 / 存入供给」决定的。借的人多，存的利息就高；借的人少，利息就低到接近 0。

### 3. 流动性挖矿（Yield / Farming）

把代币提供给某个协议（比如做 DEX 的做市商），协议给你奖励代币。

「年化收益率」（APY）看起来诱人——10%、50%、甚至几百几千。但要警惕：

- 越高的 APY，背后的风险越大
- 高 APY 大多来自「项目方发自己印的 token 当奖励」，这种 token 可能很快归零
- **本金不一定保本**，存在「**无常损失**」「**协议被黑**」等风险

### 4. 衍生品（Perp / Options）

链上的合约交易、期权交易。代表：**dYdX**、**GMX**、**Hyperliquid**。

**新手强烈不建议碰**。合约交易在中心化交易所就已经是把大多数人扎进去的工具，链上版本不会更友好。

### 5. 稳定币发行

铸造去中心化稳定币的协议本身就是 DeFi 应用。代表：**MakerDAO / Sky**（DAI / USDS 体系）、**Liquity**（发行 LUSD）。

### 6. 质押 / Restaking

把 ETH 质押到以太坊，参与维护网络，赚奖励。或者把质押凭证再质押到其他协议（restaking），赚双重奖励。

代表：**Lido**（最大的 ETH 质押服务）、**EigenLayer**（restaking 概念的开创者）

## DeFi 的真实风险

DeFi 不是免费的午餐。它把银行那一套换成了代码，但**也把银行帮你扛的风险，转嫁到了你自己头上**。

### 1. 智能合约风险

代码可能有 Bug。一个 Bug 可能让黑客把整个协议的钱全部偷走。**历史上 DeFi 协议被黑、损失上亿美元的事件多得数不清**。

防御：优先用**老牌、有名、被审计过、跑了多年且 TVL 和风险披露相对透明**的协议。审计不是免死金牌，但比完全没审计、刚上线的新协议好得多。新协议哪怕 APY 再高，第一时间冲进去 = 当试错的炮灰。

### 2. 经济模型风险

智能合约没 Bug，但**经济设计**有缺陷，导致系统在极端市场下崩溃。

例子：算法稳定币 UST 的合约本身没 Bug，但它的经济模型在挤兑面前不堪一击，3 天归零。

### 3. 预言机风险

DeFi 合约需要知道「现在 ETH 值多少钱」才能正确清算。这个价格通常由「**预言机**」（Oracle，例如 Chainlink）提供。预言机被攻击或失灵，会引发连锁清算或套利攻击。

### 4. 治理 / 中心化风险

不少号称「去中心化」的项目，实际上**控制权高度集中**在创始团队手里。他们能修改合约参数、暂停协议、增发 token——你的钱并不像你以为的那么「自治」。

### 5. 监管风险

DeFi 越来越多地引起监管注意。美国 SEC 起诉过多个 DeFi 项目，部分国家开始要求 DeFi 协议做 KYC。**未来的政策不确定性**是真实的风险。

### 6. 你自己操作失误

签错了合约、放错了链、被钓鱼、忘记取消授权…… DeFi 是「**操作责任 100% 在你**」的世界。客服？没有。

## 一个新手友好的 DeFi 入门路径

如果你想真正体验一下 DeFi，建议这个顺序，**金额从极小开始**：

1. 先把少量 ETH 存到一个 L2（比如 Base 或 Arbitrum），降低 Gas 试错成本
2. 在 Uniswap 上做一次最简单的「ETH ↔ USDC」兑换，感受签名流程
3. 在 Aave 上存一点 USDC，看看「赚利息」是什么体验
4. 体验完，把钱提出来

不要急着冲高 APY、新项目、未知协议。**先理解机制，再上规模**。理解了机制，再决定要不要深入。
