# 14. 中心化交易所 vs 去中心化交易所

## 一句话理解

CEX 是**像券商一样的公司**，DEX 是**链上的自动撮合合约**——两者各有不可替代的用途，**不是非此即彼**。

## 一个最根本的区别

如果你只记住一件事，记这个：

> **在 CEX，你的资产是「记在交易所账本上的一行数字」。**  
> **在 DEX，你的资产是「自己钱包里的链上余额」。**

这个差别延伸出几乎所有其他不同：你怎么进出金、怎么交易、谁能冻结你、出事谁负责……都从这里来。

## 详细对比

| 维度 | CEX | DEX |
|---|---|---|
| **资产保管** | 交易所托管 | 你的钱包 |
| **法币出入金** | 支持（充值人民币、美元等） | 通常不支持 |
| **KYC** | 主流 CEX 通常要求 | 协议层通常不需要；部分前端会限制地区或地址 |
| **币种深度** | 主流币种好，长尾差 | 长尾代币好（链上谁都能开池） |
| **新币速度** | 上币要审核，慢 | 项目方部署合约即可，几分钟 |
| **手续费** | 通常 0.1% 左右 | 0.05%~0.3%，加上 Gas |
| **交易速度** | 即时（链下撮合） | 等链确认，几秒到几分钟 |
| **客服 / 找回** | 有客服（虽然不一定靠谱） | 没有 |
| **被冻结风险** | 平台/监管可能冻结你的账户 | 钱包地址本身没人能封；但前端、RPC、特定 token 合约仍可能限制或冻结 |
| **挂单簿 / 高级订单** | 限价、止盈止损、网格…… | 大多只支持市价单 |
| **杠杆 / 合约** | 主流 CEX 都提供 | 部分 DEX 有 |
| **最大风险** | 交易所跑路、被黑、被监管 | 智能合约 Bug、自己手滑、钓鱼 |

## CEX 的代表

按规模和合规程度粗略分：

- **全球头部**：Binance、Coinbase、OKX、Bybit、Kraken
- **合规优先**：Coinbase（美国上市）、Kraken（美国）
- **新兴**：Bitget、Gate.io 等

不同 CEX 在不同国家可用度不一样，新手选哪家主要看：**所在地区能用、能法币出入金、有客服支持你的语言**。

## DEX 的代表

- **以太坊及多链**：Uniswap（最主流）、SushiSwap、Curve（稳定币）
- **BNB Chain**：PancakeSwap
- **Solana**：Jupiter（聚合器）、Raydium、Orca
- **聚合器**：1inch、Matcha、Jupiter

## 什么时候用 CEX，什么时候用 DEX

这是新手最实用的判断框架。按场景挑：

### 用 CEX 更合理的场景

1. **首次入金**——大多数人第一次买币，是从银行卡 / 信用卡入金到 CEX，没有更现实的渠道
2. **法币出金**——把币变回真实货币
3. **大额、主流币种交易**——CEX 流动性深、滑点小
4. **要用挂单、止损、合约**——这些工具 DEX 上要么没有，要么不好用
5. **不想自己保管资产**——是的，这也是合理需求。如果你判断自己保管资产的能力风险比交易所大，CEX 反而更安全

### 用 DEX 更合理的场景

1. **交易长尾代币**——CEX 没上的，或者新出的项目，只能在 DEX 上
2. **不想 KYC**——隐私需求（但部分官方前端可能会做地区或地址筛查）
3. **跨境、被监管限制**——CEX 可能拒绝服务你的地区；DEX 协议层更开放，但前端入口不一定开放
4. **想真正持有资产**——不放在任何中心化机构
5. **链上原生活动**——DeFi、NFT、空投，这些只能从 DEX/钱包发起

### 一个对大多数新手实用的组合

| 用途 | 建议方式 |
|---|---|
| 法币入金 → 买主流币 | 在 CEX 完成 |
| 长期持有的大额 | **从 CEX 提到自己的硬件钱包**（这一步至关重要） |
| 日常少量交易 | 钱包里少量 + DEX |
| 玩 DeFi / NFT / 空投 | 链上钱包，从 CEX 划一小部分过来用 |
| 想出金变现金 | 转回 CEX → 提现 |

注意「**从 CEX 提到自己钱包**」这一步。新手最常见的失误就是**把币长期放在 CEX 里**——FTX、Mt.Gox、几次小所暴雷，每次都有一大批人血本无归。

> **不是你的钥匙，不是你的币。**

## CEX 的真实风险（必须知道）

CEX 不是「保险柜」。它的风险结构是：

### 1. 交易所跑路 / 暴雷

历史上有过：

- **Mt.Gox（2014）**：曾经全球最大的比特币交易所，被黑亏损 85 万 BTC，破产
- **FTX（2022）**：曾排名前三的交易所，挪用用户资金，几天内倒闭，受害者上百万
- **若干中小交易所**：跑路、关停、突然停止提币

这些事件每次都有人安慰自己「大所不会出事」——直到 FTX 让所有人闭嘴。

### 2. 监管 / 合规风险

- 你所在国家的政策变了，CEX 不再服务你 → 资产可能短期内提不出来
- 美国 OFAC 把某地址列入制裁名单 → CEX 配合冻结
- 中国大陆禁止加密交易 → 国内用户基本只能用海外所，且法律灰色

### 3. 个人账户被风控

CEX 的风控系统会因为各种原因冻结账号：

- 异常登录、异常提币
- 被关联到「可疑地址」（哪怕你只是收过一笔正常转账）
- 监管要求配合调查

被冻了之后能不能解冻、多久能解，**完全看交易所心情和监管要求**。

### 4. 提币延迟 / 限制

「拥堵」「维护」「合规审查」都可能让你的提币卡上几天甚至几周。

### 综合结论

**CEX 用来交易、出入金，不用来长期保管资产**。这是 Web3 老玩家的共识。

## DEX 的真实风险（也必须知道）

DEX 不是「绝对安全」。它的风险只是换了一种：

1. **智能合约 Bug**——见 [DeFi 章节](../04-applications/01-defi.md)
2. **钓鱼网站**——假 Uniswap、假 PancakeSwap，长得一模一样
3. **滑点 / MEV / 夹子**——见 [DEX 章节](../04-applications/02-dex.md)
4. **假币 / 仿冒池**——名字一样合约不同，**核对合约地址**
5. **你自己签错** —— [签名章节](../02-wallets/03-signing.md) 讲过的所有风险都在

还要补一条常被忽略的风险：DEX 里资产虽然在你钱包，但**某些 token 本身仍是中心化合约**。比如部分稳定币合约有冻结地址的能力，前端网站也可能因为合规要求屏蔽某些地区或地址。

简单说：**CEX 把风险集中在交易所；DEX 把风险分散到每一个签名按钮、每一个合约和每一个入口**。

## 选择决策树（给新手）

```
你是要做这件事？
├── 第一次买币、要法币入金
│   └── 用 CEX
├── 长期持有大额
│   └── 从 CEX 提到自己的硬件钱包，不要长期放在 CEX
├── 想玩 DeFi / NFT / 链上空投
│   └── 必须用钱包 + DEX（CEX 帮不到你）
├── 想交易 CEX 上没有的小币种
│   └── 用 DEX（但小心仿冒、滑点、跑路盘）
├── 想用挂单、合约
│   └── 用 CEX
└── 想把币变成现金
    └── 转回 CEX 提现
```

## 怎么记这一章

| 关键点 | 一句话 |
|---|---|
| CEX 本质 | 像券商，资产托管在公司 |
| DEX 本质 | 像合约，资产在你钱包 |
| 法币出入金 | 几乎只能靠 CEX |
| 长期持有 | 一定要自己钱包，最好硬件钱包 |
| 链上活动 | 必须用 DEX/钱包 |
| 共存关系 | 不是二选一，各有不可替代的用途 |
