# 01. 什么是 Web3

## 一句话理解

Web3 是「**用户自己拥有账号和资产**」的互联网。

## 用 Web2 对照着看

你现在用的互联网，可以叫它 Web2。它有几个我们习以为常、但其实挺关键的特点：

- 你的微信账号属于腾讯，淘宝账号属于阿里。账号被封了，里面的好友、订单、评价就都没了。
- 你在抖音发的视频，能不能被人看到，是平台的算法说了算。
- 你存在支付宝里的钱，本质上是支付宝「记账」记下来的一行数据，平台说冻结就冻结。

Web2 的世界里，**平台是账本，平台说了算**。这本来没什么问题——我们享受了十几年免费、便捷的服务，代价是把数据和资产托管给了平台。

Web3 想换一种活法：

- 你的账号是一串只有你拿得到「钥匙」的地址，不归任何公司管。
- 你的资产记录在一个**所有人都能看、但很难被单方面篡改**的公共账本上（也就是区块链）。
- 你和别人交互，是钱包对钱包。协议层通常没有客服、没有注册审核，也没有一个平台能直接把你的钱包地址「封号」。

这里要留一个边界：如果你持有的是 USDT、USDC 这类由公司发行的 token，发行方的合约可能有冻结能力；如果你通过某个网站前端访问协议，网站也可能屏蔽某些地区或地址。Web3 让你掌握钥匙，但不代表所有链上资产都完全不受中心化规则影响。

一句话总结这个差别：

> **Web2 是「你登录进平台」，Web3 是「平台连接到你的钱包」。**

## 一个具体的对比

假设你想给国外的朋友转 100 美元。

**Web2 路径**：
你打开银行 App → 银行查你的账户 → 银行联系国外银行 → 中间可能还要过 SWIFT、清算行 → 朋友的银行收到 → 朋友的账户加 100 → 你的账户减 100。

整条链路上有 N 个机构在帮你「记账」，每一段都收一点费、花一点时间，任何一个环节都可以拒绝你。

**Web3 路径**：
你打开钱包 → 输入朋友的地址 → 签个名 → 几秒到几分钟后，公共账本上记录：你的地址减 100，朋友的地址加 100。

中间没有银行、没有 SWIFT，也不需要朋友所在国家的金融系统配合。这件事是好是坏，先不评价，但它**确实是一种新的可能性**。

## 那「去中心化」到底是什么意思

「去中心化」是 Web3 被说得最多、也最容易让人犯困的词。其实没那么玄：

中心化 = **有一个老板说了算**。微信群有群主，淘宝有阿里，银行有总行。

去中心化 = **没有老板，规则提前写好，所有人按规则办事**。

打个比方：

- 中心化像**公司**——CEO 拍板，员工执行。
- 去中心化像**红绿灯下的路口**——没人指挥，但大家看灯走，秩序是规则带来的，不是某个人带来的。

区块链就是那个「红绿灯」。它不归任何公司管，但所有人都按它的规则走。

## Web3 ≠ 加密货币 ≠ NFT ≠ 元宇宙

这几个词经常混着用，但它们不是同一个东西：

| 词 | 它是什么 |
|---|---|
| **区块链** | 那本「谁都能看、很难单方面篡改」的账本，是底层技术。 |
| **加密货币** | 在这个账本上流通的「钱」，比如比特币（BTC）、以太币（ETH）。 |
| **NFT** | 在这个账本上的「独一无二的物品」，比如一张图、一个域名。 |
| **Web3** | 用上述这些东西搭起来的、用户自己掌握账号和资产的互联网。 |
| **元宇宙** | 一种「沉浸式 3D 互联网」的设想，跟 Web3 有交集但不是一回事。 |

简单记：**区块链是地基，加密货币和 NFT 是地基上的东西，Web3 是用这些东西盖起来的房子。元宇宙是另外一栋楼。**

## 那它现在到底能干嘛

老实说，截至 2026 年，Web3 还在很早期。大部分人接触到它的方式，主要是这几种：

1. **持有加密货币**——把它当成一种新的资产类别（风险自负）。
2. **跨境转账和支付**——尤其在传统金融不发达的地区，稳定币用得越来越多。
3. **NFT 和数字收藏品**——证明「这张图/这个会员资格是我的」。
4. **DeFi（去中心化金融）**——不通过银行做借贷、兑换、理财。
5. **链上身份**——用一个钱包地址登录各种应用，不用每个网站都注册账号。

这些场景哪些会留下来、哪些会消失，没人能打包票。但「让用户自己掌握账号和资产」这件事，是 Web3 区别于过去互联网的根本。
