# 08. 代币、Token、Coin

## 一句话理解

**Coin** 是一条链自己的「原生货币」，**Token** 是别人在这条链上发的「凭证」——两者都中文叫「代币」，但出身完全不同。

## 这两个词中文都叫「代币」，但其实不一样

中文世界里 Coin 和 Token 经常混着叫「代币」，导致初学者一头雾水。英文里区别其实挺清楚：

| | Coin | Token |
|---|---|---|
| 谁发的 | 这条链本身 | 任何人，靠智能合约发 |
| 例子 | BTC、ETH、SOL、BNB | USDT、UNI、SHIB、PEPE |
| 作用 | 付 Gas、维护链的安全（PoS 质押） | 做应用层的各种事——稳定币、治理、积分、玩具 |
| 想发一个 | 你得做一条新链 | 写几十行代码就能发 |

一个比方：

> **Coin 像「国家发行的法定货币」**——美元只能在美国央行体系里铸造。  
> **Token 像「商场里的购物券、健身房的会员卡、迪士尼的乐园币」**——商场只要遵守国家法律，就可以印自己的券。

「商场」就是这条链，「国家」就是这条链本身的协议规则。

所以你会看到：以太坊（链）的原生 coin 是 ETH，但以太坊上跑着几十万种 token——USDT、UNI、各种 meme 币——它们都是「在以太坊这个商场里发的购物券」。

## 「代币标准」是什么意思

你可能听过 **ERC-20**、**ERC-721**、**SPL**、**BRC-20** 这些词。它们都是「**代币标准**」。

代币标准 = 一份**约定俗成的接口规范**，告诉所有人：「凡是按这个标准发的代币，都长这样、有这些函数」。

为什么需要标准？因为代币要被很多东西支持——钱包要能显示余额、交易所要能上架、DEX 要能兑换。如果每个代币都长得不一样，谁都没法对接。有了标准，所有应用按一套规则做适配，就能支持一大批代币。

最常见的几个：

| 标准 | 在哪 | 用来做什么 |
|---|---|---|
| **ERC-20** | 以太坊及所有 EVM 链 | 「同质化代币」——一份和另一份完全等价，比如 USDT、UNI |
| **ERC-721** | 以太坊及所有 EVM 链 | 「非同质化代币」（NFT）——每一份都不一样，第 10 章细讲 |
| **ERC-1155** | 以太坊及所有 EVM 链 | 同时支持同质化和非同质化，游戏道具常用 |
| **SPL** | Solana | Solana 上的代币标准 |
| **BRC-20** | 比特币 | 比特币生态尝试做的 token，结构特殊 |

新手只要知道一件事：**看到「ERC-20 代币」，意思是「以太坊系链上的某个 token」**。

## 同质化 vs 非同质化

这是一对重要的概念区分：

- **同质化（Fungible）**：每一份都一样，1 个 USDT 和另 1 个 USDT 完全可互换，就像 1 块钱和另 1 块钱没区别。
- **非同质化（Non-Fungible）**：每一份都独一无二，#1 号 NFT 和 #2 号 NFT 是两个不同的东西，就像两张不同号码的演唱会门票。

ERC-20 是同质化代币，ERC-721 是非同质化代币——后者就是大家熟悉的 NFT。

## 一个新手最常踩的坑：同名代币不同链

链上 token 不需要审批，**任何人都能发**。这导致一个让无数新手中招的事情：

> **同一个名字的代币，在不同链上，是完全不同的东西。**

举个真实场景：你想买 USDT。USDT 在多条链上都有发行版本：

- 以太坊上的 USDT（ERC-20）
- Tron 上的 USDT（TRC-20）
- BNB Chain 上的 USDT（BEP-20）
- Solana 上的 USDT（SPL）
- ……

它们**都代表 Tether 发行的 USDT、都试图锚定 1 美元**，但**所在网络不一样**。如果你从交易所提币时选错网络，结果可能是：

- 地址格式不兼容，交易所直接拦截，不让你提；
- 地址格式兼容，资产到了另一条链上，但收款方钱包/交易所不支持，找回非常麻烦；
- 收款地址根本不是你控制的地址，那就几乎无法挽回。

所以不要只问「是不是 USDT」，还要问：**是哪条链上的 USDT**。

更可怕的情况：骗子发一个**名字一模一样的假币**。

> 真的 USDT 合约地址：以太坊上是 `0xdAC17F958D2ee523a2206206994597C13D831ec7`  
> 骗子可能发一个 token，名字也叫 USDT，合约地址完全不同。

钱包默认会显示**名字**，新手看名字一样就以为是同一个，其实合约地址完全是另一回事。

**保命习惯**：

1. **提币选链时仔细看**——交易所提币、跨链时，把「网络」/「链」选对，反复核对
2. **看合约地址，不只是看名字**——任何时候要确认一个 token 是真是假，去官网或 CoinGecko/CoinMarketCap 查合约地址
3. **别相信钱包里突然出现的不明 token**——「空投」一些恶心代币是常见钓鱼手法，下一节细讲

## 「空投到我钱包的奇怪 token，能不能动？」

你打开钱包，发现里面突然多了一些没买过的代币，名字花里胡哨——`Visit website to claim`、`Reward 1000 USDT` 等等。

**不要碰它们**。这些是「**毒空投**」（dust attack / scam airdrop），常见的几种套路：

1. **诱导你访问钓鱼网站**：代币名字本身就是网址，诱你去访问后签名授权，钱被搬走。
2. **诱导你授权或兑换**：你想把这个币卖掉变现，结果点了卖出，签名时实际授权的是清空你的真实资产。
3. **追踪关联钱包**：通过你处理空投币的方式，把你的多个钱包地址关联起来。

正确做法：**当它不存在**。大多数钱包支持隐藏代币——眼不见心不烦。不要点、不要卖、不要送给别人、不要好奇研究。

## Token 还可以分成哪些类型（按用途）

按发的目的，token 大致可以分几类——这是市场的粗分法，没那么严格：

| 类型 | 用来干嘛 | 例子 |
|---|---|---|
| **稳定币** | 锚定法币，作交易媒介 | USDT、USDC、DAI（下一章细讲） |
| **治理代币** | 持有就有投票权，能决定协议怎么改 | UNI（Uniswap）、AAVE |
| **平台币** | 某个生态的「燃料」「会员卡」 | BNB、OKB |
| **Meme 币** | 文化梗，没什么基本面，纯靠社区情绪 | DOGE、SHIB、PEPE |
| **GameFi/SocialFi 代币** | 某个链上游戏/社交应用的积分 | 各种 |
| **RWA（现实资产代币）** | 把现实世界的资产（黄金、国债）上链 | PAXG、各种代币化国债 |

记住这些分类不重要，重要的是：**每一种 token 的「价值来自哪里」是不一样的**。稳定币靠美元储备，治理代币靠协议的现金流和治理权，meme 币靠情绪——别把它们当成同一类东西。
