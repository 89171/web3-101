# 10. NFT

## 一句话理解

NFT 是**链上发行的独一无二的凭证**——它本身不是图片，而是「证明某个东西归你」的产权证。

## 先纠正一个最常见的误解

很多人以为：「NFT = 那张猴子图」。这个理解是错的。

更准确的说法是：

> **NFT 是链上的一条记录，记着「编号 X 这个东西，现在的主人是地址 Y」。**

那张猴子图，绝大多数情况下**并不在链上**——它存在某个服务器或者 IPFS 上。链上只存了一个指针（URI），告诉所有人「编号 X 关联的图在那个地址」。

所以买 NFT，你**真正得到的是**：

1. 链上「这个编号属于你」的记录
2. 关联的元数据（图片、视频、描述等，可能在链下）
3. 项目方可能附加的权益（社区准入、版税分成、IP 使用权等，**取决于具体项目，没有统一标准**）

你**没有**：
- 自动获得这张图的版权（除非项目方明确授权）
- 阻止别人把这张图右键另存为的能力——任何人都能保存图片，但**链上「编号属于你」的记录还是你的**

> 类比：你买一幅画的所有权证书。  
> 别人可以拍照、印海报、做表情包——但「这幅画的所有者是 X」这件事，写在产权登记处。

## 它和「同质化代币」有啥根本区别

回到第 8 章那个区分：

| | 同质化代币（ERC-20） | 非同质化代币（ERC-721） |
|---|---|---|
| 比方 | 钱 | 房产证 / 演唱会门票 |
| 每一份 | 完全等价 | 各不相同 |
| 单位 | 可以拆，0.5 个 | 标准 NFT 通常只能整存整取；除非额外做碎片化封装 |
| 标识 | 余额（数量） | 编号（哪一个） |
| 例子 | USDT、ETH | CryptoPunks #1234、某张演唱会门票 |

所以 NFT 适合表示「**这一个东西是这一个，跟别的不一样**」的场景。

## NFT 实际在用的几种场景

第一波 NFT 热潮（2021~2022）几乎全是头像和数字艺术。市场冷下来之后，能留下的 NFT 用例慢慢清晰：

### 1. 数字艺术品 / 收藏品

最早的用法，市场最大但泡沫也最大。

代表：CryptoPunks、Bored Ape Yacht Club、Art Blocks 等。

特点：
- **价格波动巨大**，多数项目从高点跌 90%+ 是常态
- 价值高度依赖**社区氛围**和**品牌运营**，不是底层技术
- 真正能穿越周期的项目极少

### 2. 域名 / 身份

把人类可读的名字解析成钱包地址。

代表：
- **ENS**（`.eth` 域名）——把 `vitalik.eth` 解析成那一串 0x 地址
- **SNS**（`.sol` 域名，Solana）
- **Unstoppable Domains** 等

用途：转账时不用复制粘贴一串乱码，输入 `alice.eth` 就行。

### 3. 链上凭证 / 会员卡

证明你是「某个东西」的成员或参与者：

- 项目方的早期支持者徽章
- 活动出席证明（POAP）
- 某社区的入场凭证

特点：通常不可转让（soulbound），存在的目的不是交易，而是身份认证。

### 4. 游戏道具

游戏里的装备、皮肤、土地用 NFT 表示。

理想情况：你拥有的道具是你的，可以跨游戏使用、随时变卖。  
现实情况：大部分链游做得很差，玩家体验远不如传统游戏，热度起来又落下去。

### 5. 现实资产凭证（早期实验）

把房产、奢侈品、收藏品的「所有权证明」上链。这块还在早期，主要受限于现实世界的法律承认问题——链上写你是房子的主人，不代表法院认。

## 怎么判断一个 NFT 项目值不值得买（如果你想买）

这本书不给投资建议，但有几个判断维度可以分享，帮你少踩坑：

1. **项目方是谁？匿名还是实名？**有没有可追溯的过往？匿名项目跑路成本极低。
2. **它要解决什么问题？还是只是「漂亮的图」？**纯图片项目要靠社区文化撑很多年，绝大多数撑不下去。
3. **持有这个 NFT 你具体能干嘛？**有没有具体的权益、用途，还是仅仅「持有」？
4. **流动性如何？**地板价、24h 成交量。流动性差的 NFT 你买进去可能一年都卖不出。
5. **历史价格 vs 现在价格。**很多项目高点接盘的人到现在还套着 90%。

更重要的态度建议：

> **把 NFT 当兴趣支出，不要当投资。**  
> 「能卖出比买入更高的价格」对绝大多数 NFT 项目不成立。如果你买这张图就是单纯喜欢、想支持这个艺术家/项目，那 OK；如果是为了升值，做好血本无归的心理准备。

## NFT 相关的安全坑

NFT 是钓鱼诈骗的重灾区，因为：

- 大家容易激动（怕错过铸造、错过白名单）
- 操作流程复杂，签名内容看不懂
- 一个 `setApprovalForAll` 签名就能让一整套 NFT 被搬空

### 高频陷阱

1. **假的 mint 网站**：项目方真域名是 a.com，骗子搞个 a-mint.com，Twitter 评论区一发，急着 mint 的人冲进去，签个名 NFT 没了。
2. **OpenSea 上的「免费 NFT」骚扰**：钱包里突然多了一个 NFT，标题是「点击领奖」。同上一章讲的毒空投，**不要碰**。
3. **`setApprovalForAll` 钓鱼**：让你授权某个合约「能动你这个系列所有 NFT」，授权之后骗子把你的整套 NFT 转走。
4. **OTC 钓鱼**：陌生人 DM 你说要买你的 NFT，给你发一个看起来是 OpenSea 的链接——其实是钓鱼。

### 防御原则

- 任何 mint 链接都从**项目官方 Twitter 置顶**进，别从评论区点
- 钱包里看不懂的 NFT，**不要点、不要授权、不要转**
- 定期到 [revoke.cash](https://revoke.cash/) 取消用不到的 NFT 授权
- 大额 NFT 放冷钱包，日常用的热钱包里别放贵的

## 一个常被问的问题：版权

「我买了一个 NFT，那张图我能随便用吗？」

答：**取决于项目的授权条款**，没有统一规则。

常见几种：

- **完全商业授权**（Bored Ape 等）：你可以拿这张图开公司、印 T 恤、当商标
- **仅个人使用**（CryptoPunks 早期）：可以做头像、晒朋友圈，不能商用
- **只是持有**（很多小项目）：版权完全归项目方，你只是有个持有记录

买之前，**找到项目的 License 条款**看清楚。否则你以为买的是 IP 授权，其实只买了一张 jpeg 的指针。
