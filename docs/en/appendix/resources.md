# Appendix B: Recommended Resources

> This handbook focuses on beginner concepts and cannot cover everything. The resources below are useful starting points. Domains, ownership, and availability can change, so always verify official links before using tools.

## Learn Concepts

- **Bankless**: long-running Web3 media and podcast.
- **a16z crypto**: essays and research from the a16z crypto team.
- **Vitalik Buterin's blog** (`vitalik.eth.limo`): one of the best sources for Ethereum's long-term direction.
- **Paradigm Research**: technical and market research.
- **Messari**: data and research reports.

## On-Chain Data

- **Etherscan / Solscan / TronScan**: block explorers for Ethereum, Solana, and Tron.
- **DeFiLlama**: DeFi TVL, chain shares, and ecosystem data.
- **CoinGecko / CoinMarketCap**: prices, market caps, and contract addresses.
- **Dune**: community-built on-chain dashboards.

## Wallets and Trading

> These are mainstream options, not recommendations. Verify current status yourself.

**Hot wallets**

- **MetaMask**: mainstream Ethereum/EVM browser wallet.
- **Rabby**: wallet with strong transaction risk prompts.
- **Phantom**: popular in the Solana ecosystem.
- **OKX Wallet / Trust Wallet / imToken**: multichain wallets.

**Hardware wallets**

- **Ledger**
- **Trezor**
- **OneKey / Keystone**

**CEXs**

- Global major exchanges: Binance, Coinbase, OKX, Bybit, Kraken
- Compliance-oriented in the US: Coinbase, Kraken

## Security Tools

- **revoke.cash**: review and revoke token approvals.
- **Etherscan Token Approval Checker**: approval review for Ethereum.
- **Pocket Universe / Wallet Guard**: browser extensions that warn before risky signatures. Verify current trustworthiness.
- **Scam Sniffer**: phishing detection and security research.

## News and Communities

- **X / Twitter**: still central to Web3 information flow. Follow official accounts and avoid comment links.
- **Discord**: project communities. Do not trust DMs.
- **Telegram**: common in many regions, also full of scammers.
- **Reddit**: `r/cryptocurrency`, `r/ethereum`, `r/Bitcoin`.

## Chinese Resources

- **DengLian Community** (`learnblockchain.cn`): developer-focused Chinese articles.
- **PANews / BlockBeats / Foresight News**: Chinese crypto media. Quality varies.
- **Chinese translations of Vitalik's blog**: some community translation projects exist.

## Learn Development

- **CryptoZombies**: beginner Solidity learning through games.
- **Speed Run Ethereum**: project-based Ethereum development.
- **Solidity by Example**: Solidity examples.
- **Ethernaut**: smart contract security challenges by OpenZeppelin.
- **Solana Cookbook / Anchor Book**: Solana development.
- **Ethereum developer docs**: official and free.

## Researching Projects Seriously

At minimum, check:

1. **Official website and whitepaper**: what are they building?
2. **Code repository**: is development active?
3. **Block explorers**: contract age, token distribution, large holders.
4. **DeFiLlama**: TVL and trend.
5. **Discord / X**: community activity, keeping in mind it can be faked.
6. **CoinGecko token details**: supply, unlocks, contract addresses.

If you cannot find basic information, the project may not deserve your time.

## Final Habit

- Bookmark official channels.
- Treat unfamiliar sources as suspicious by default.
- When confused, return to fundamentals before trusting social media explanations.
- Slow is fast in Web3. Missing an opportunity is cheaper than losing a wallet.
