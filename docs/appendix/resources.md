# 附录 B：推荐资源

> 这本手册讲的是「入门概念」，不可能覆盖所有细节。下面是一些**值得长期跟随**的资源——按用途分类。

> ⚠️ **免责声明**：列出的工具/网站可能随时间发生变化（域名、所有权、可用性）。在使用前请自行核实最新的官方域名，**不要从本文档直接复制链接到地址栏**——这是一个好习惯，对任何文档都一样。

## 学概念（深入理解）

读完这本手册之后，如果你想更系统地学，推荐这些英文资源（中文优质内容偏少）：

- **Bankless** —— 老牌 Web3 媒体和播客，文章和访谈结合，适合长期跟读
- **a16z crypto** —— a16z 的 crypto 团队博客，文章偏深度
- **Vitalik Buterin 的博客**（vitalik.eth.limo）—— 以太坊创始人的个人博客，是了解长期方向的最佳来源
- **Paradigm Research** —— Paradigm 基金的研究文章
- **Messari** —— 行业数据 + 研究报告

## 看链上数据

- **Etherscan**（以太坊）/ **Solscan**（Solana）/ **TronScan**（Tron）—— 链上浏览器，查任何地址、交易、合约的状态
- **DeFiLlama** —— 看各 DeFi 协议的 TVL、各链份额、各种统计数据，**没有广告，相对客观**
- **CoinGecko / CoinMarketCap** —— 查代币价格、合约地址、市值，**确认代币真假的常用工具**
- **Dune** —— 社区自建的链上数据看板，能查到非常细的链上数据

## 钱包和交易

> 不推荐具体使用，但列出主流选项，你自己核实当前情况。

**热钱包**：
- **MetaMask** —— 最主流的以太坊系浏览器插件钱包
- **Rabby** —— 比 MetaMask 安全提示更好的钱包（开源）
- **Phantom** —— Solana 生态最常用
- **OKX Wallet / Trust Wallet / imToken** —— 多链支持的手机钱包

**硬件钱包**：
- **Ledger**（法国）
- **Trezor**（捷克，更开源）
- **OneKey / Keystone**（中国团队）

**主流 CEX**（按规模和合规分类，自行选择）：
- 全球头部：Binance、Coinbase、OKX、Bybit、Kraken
- 合规优先（美国）：Coinbase、Kraken

## 安全工具

- **revoke.cash** —— 检查并撤销代币授权
- **Etherscan 的 Token Approval Checker** —— 同上，原生工具
- **Pocket Universe / Wallet Guard** —— 浏览器扩展，会在你签名前解析风险（**自行核实当前可信度**）
- **Scam Sniffer** —— 钓鱼网站检测

## 新闻 / 行情 / 社区

- **Twitter（X）** —— 仍然是 Web3 信息流的核心。**关注项目方官方账号**，不要相信评论区链接
- **Discord** —— 项目官方社区。**只在官方 Discord 内沟通**，不要相信任何 DM
- **Telegram** —— 中文/俄语/亚洲社区常用，**骗子也最多**
- **Reddit**：`r/cryptocurrency`、`r/ethereum`、`r/Bitcoin` —— 比 Twitter 信噪比好一些

## 中文资源（少，但有）

- **登链社区**（learnblockchain.cn）—— 开发者向，文章质量不错
- **PANews / 律动 BlockBeats / Foresight News** —— 中文加密媒体（注意信息质量参差不齐）
- **Vitalik 博客的中文翻译版**（有民间翻译项目）

## 学开发（如果你想从用户变开发者）

- **CryptoZombies**（cryptozombies.io）—— 用游戏方式学 Solidity，新手入门很经典
- **Speed Run Ethereum**（speedrunethereum.com）—— 由 BuidlGuidl 维护，做实际项目学开发
- **Solidity by Example**（solidity-by-example.org）—— 用例子学 Solidity
- **Ethernaut**（ethernaut.openzeppelin.com）—— 通过破解漏洞学安全
- **Solana Cookbook**、**Anchor Book** —— Solana 开发入门
- **以太坊官方文档**（ethereum.org/developers）—— 权威且免费

## 想严肃投资 / 研究项目

> 这本书不推荐任何项目，但提供工具帮你自己判断。

研究一个项目，至少看这几样：
1. **项目官网 + 白皮书** —— 了解他们在做什么
2. **代码仓库**（GitHub）—— 是不是真的有人在写代码？多久没更新了？
3. **Etherscan / Solscan** —— 合约部署时间、持币分布、大户地址
4. **DeFiLlama** —— TVL 趋势
5. **Discord / Twitter** —— 社区活跃度（注意：可以刷的）
6. **CoinGecko 的 token 详情** —— 流通量 / 总量 / 解锁计划，**很多项目的"低市值"是因为大量代币还没解锁**

如果上面这些都查不到东西，**这个项目很可能不值得你投入精力**。

## 一个总结性的习惯建议

- **官方渠道收藏到书签**，从书签进入
- **任何陌生信息源都默认怀疑**，再次确认才相信
- **遇到不懂的概念，先回到这本手册或 Vitalik 博客查**，不要去信社交媒体上的「权威解读」
- **慢就是快**——Web3 的「错过」成本远小于「踩坑」成本
